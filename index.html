    Prompt

    Your password stays on this device. Only a short scrambled code is checked online.

    How this works

    When a prompt contains a password, your browser hashes it with SHA-1 and sends only the first 5 characters of the hash to the free Have I Been Pwned Pwned Passwords API. The password and its full hash never leave this browser, and only counts are saved. Have I Been Pwned sees the request (and your IP address), not the password. Runs on your next Inspect. Off again next time you open the page.

    Setup

    Install the extension for ChatGPT, Claude and Gemini, then choose what happens to each kind of data. To try the checks without installing anything, use the Try it tab.

    Install in Chrome

    Free

    Download the Chrome extension

    1. Unzip ai-firewall-extension.zip. You get a folder with manifest.json at the top of it.
    2. In Chrome or Edge, go to chrome://extensions or edge://extensions.
    3. Turn on Developer mode in the top-right corner.
    4. Click Load unpacked and choose the folder that contains manifest.json.
    5. Pin it from the Extensions menu, then open ChatGPT, Claude, or Gemini and look for AI Firewall · Protected locally.

    Keep the folder on your computer. Chrome runs the extension from it.
